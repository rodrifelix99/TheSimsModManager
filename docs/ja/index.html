🖼️

本物のサムネイルと中身の内訳

アプリが .package ファイルの中を見て、実際の画像を取り出します。あわせて中身の内訳も表示：CAS パーツ、オブジェクト、テクスチャ、チューニング。

🔀

ワンクリックで有効・無効

スイッチを切り替えるだけで、削除せずに MOD をオフにできます。ファイル名を変えてゲームに読み飛ばさせるだけなので、いつでも戻せます。

⚠️

競合の警告

同じ MOD を二重に入れていたり、古いバージョンを新しいものと並べたままだったり。どちらにも印がつきます。さらにパッケージの中身まで見て、互いのリソースを上書きしている MOD を指摘します。CC が壊れる本当の原因はここです。

📦

ドラッグして、離すだけ

ファイルでもフォルダごとでも、ウィンドウに落とせば正しい場所に収まります。.zip・.rar・.7z は自動で展開され、フォルダ構成はそのまま、readme やスクリーンショットは除かれます。

翻訳されたフォルダ名（「Los Sims 3」など）、Ultimate Collection、OneDrive に移動されたドキュメント、同じゲームの複数インストール。全部見つけますし、だめなら手動で指定できます。

よくある質問にお答えします。

本当に無料ですか？

はい。ダウンロードも利用も無料で、アカウントも広告も「Pro 版」もありません。もし週末が救われたら開発者にコーヒーをおごることもできますが、完全に任意です。

MOD やセーブデータが壊れることはありますか？

MOD の無効化はファイル名を変えるだけ（.disabled を付けるだけ）で、ゲームがそれを読み飛ばします。何も削除されませんし、有効に戻せば元のファイルがそのまま返ってきます。セーブデータには一切触れません。

Windows に「認識されないアプリ」と出ます。安全ですか？

まだコード署名をしていないため（無料プロジェクトには証明書が高くつきます）、初回起動時に SmartScreen が警告を出します。詳細情報 → 実行を選んでください。配布ファイルは GitHub のサーバー自身が自動でビルドして公開しているので、途中で誰かが手を加えることはできません。

Ultimate Collection や各言語版のゲームでも動きますか？

動きます。翻訳されたユーザーフォルダ（「Los Sims 3」「Die Sims 2」など）、シムズ 2 の Ultimate Collection、OneDrive に移動されたドキュメントフォルダ、同じゲームの複数インストールを検出します。どうしても見つからないときは、手動でフォルダを指定できます。

不具合の報告や機能のリクエストはどこへ？

アプリの中からどうぞ：設定 → 不具合を報告（または機能をリクエスト）を開くと、アプリのバージョン・OS・今のゲームが自動で入力されます。Tumblr でのメッセージも歓迎です。
