真实预览图和内容明细

应用会打开你的 .package 文件，把里面真正的图片取出来，还会列出内容构成：CAS 部件、物件、贴图、调参文件。

一键启用或停用

点一下开关就能关掉任何 MOD，而不是删掉它。文件只是被重命名，让游戏跳过它，随时可以再打开。

冲突提醒

同一个 MOD 装了两遍，或者新旧版本放在一起？两个都会被标出来。应用还会读取包内数据，找出互相覆盖资源的 MOD，这才是 CC 出问题的真正原因。

模拟人生正传全系列，外加中世纪。

每部游戏放 MOD 的地方都不一样。这个应用都记得。

The Sims

2000

MOD 放在安装目录下的 Downloads 文件夹，而不是「文档」。应用分得清。

The Sims 2

2004

既认得「文档」里标准的 EA Games 文件夹，也认得 Ultimate Collection 自己那套文件夹名。

The Sims 3

2009

必须先有 Resource.cfg 框架才能加载 MOD；应用会帮你建好。

The Sims Medieval

2011

MOD 放在安装目录里而不是「文档」，还需要一个 Resource.cfg；这两样应用都会替你准备好。

The Sims 4

2014

用的就是常见的 Mods 文件夹。记得在游戏选项里打开自定义内容和脚本 MOD。

这些位置都只是聪明的默认值，你可以在设置里让任何游戏指向任何文件夹。模拟城市已列入开发计划，而且这个应用从一开始就是按「任何能装 MOD 的游戏都能接进来」来做的。

常见问题，一并回答。

真的是免费的吗？

是。下载和使用都免费，没有账号、没有广告，也没有所谓的「专业版」。如果它替你省下了一个周末，可以请开发者喝杯咖啡，但完全随意。

它会弄坏我的 MOD 或存档吗？

停用 MOD 只是给文件改个名（加上 .disabled 后缀），好让游戏跳过它；什么都不会被删除，重新启用后拿回来的就是原本那个文件。存档从头到尾都不会被碰。

Windows 说这个应用无法识别，安全吗？

应用还没有做代码签名（对一个免费项目来说证书太贵了），所以 SmartScreen 首次运行时会提示。选择更多信息 → 仍要运行。全部源代码都公开在 GitHub 上，每一个安装包都由 GitHub 自己的服务器从这些代码自动构建。

支持 Ultimate Collection 和各语言版本的游戏吗？

支持。它能识别本地化的用户文件夹（「Los Sims 3」「Die Sims 2」……）、模拟人生 2 的 Ultimate Collection、被 OneDrive 挪走的「文档」文件夹，以及同一游戏的多个安装。实在都找不到，也可以手动指定任意文件夹。

在哪里报告问题或者提需求？

在 GitHub issues 页面；非常欢迎反馈问题和想法。另外还有一个 wiki，里面有使用指南和常见问题。
